# DirtyBrown’s level-30 Priest guide

A personal character guide from Sekilov for DirtyBrown, featuring his Horde Undead Priest, **Daddy’s Tweaker**.

The page puts the 0/0/21 Shadow setup first, then shows the 21-point Discipline and Holy alternatives, matching gear targets, the three dungeon route and a compact PvP playbook. Item and talent icons are stored with the page. It makes no Auction House requests and has no analytics, account form or external font dependency.

The guide uses current Forever client talent and item records plus retained, labelled dungeon-acquisition leads. It does not read the character’s live equipment, prove ownership of spent talent points, or claim measured PvP results.

The hosted GitHub Pages version is public, as is this repository. The page asks search engines not to index it, but the source and page remain accessible to anyone with the link. It was made as a personal, noncommercial World of Warcraft fan guide; the screenshot and original game artwork remain Blizzard property.
