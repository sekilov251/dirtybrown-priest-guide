# DirtyBrown’s level-30 Priest guide

A personal character guide from Sekilov for DirtyBrown, featuring his Horde Undead Priest, **Daddy’s Tweaker**.

The page puts the 0/0/21 Shadow setup first, then shows the 21-point Discipline and Holy alternatives, matching gear targets, a compact PvP playbook, and a personal atlas for Shadowfang Keep, Blackfathom Deeps and Razorfen Kraul. The atlas contains 118 searchable NPC records, gear targets, route landmarks, cautions, and Classic-reference coordinates where available. Item and talent icons are stored with the page. It makes no Auction House requests and has no analytics, account form or external font dependency.

The guide uses current Forever client talent and item records plus retained, labelled dungeon-acquisition leads. Its dungeon maps are client composites from build 1.60.1.70124. NPC XYZ positions, ability associations and many item-source assignments are marked as Classic/reference leads; current Beta spawns, casts, and drop rates are not claimed. Route cautions are not measured heat-map data. The guide does not read the character’s live equipment, prove ownership of spent talent points, or claim measured PvP results.

The hosted GitHub Pages version is public, as is this repository. The page asks search engines not to index it, but the source and page remain accessible to anyone with the link. It was made as a personal, noncommercial World of Warcraft fan guide; the screenshot and original game artwork remain Blizzard property.
